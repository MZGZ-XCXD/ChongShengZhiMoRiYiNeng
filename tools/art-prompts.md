# 出图提示词清单

由 `tools/gen-art.js --dump` 生成。可以直接复制去任何出图工具，画风段是固定的，只换「主体」那一行就不会跑偏。

文件名必须按 id 命名，放在对应目录下（见 assets/README.md）。

## 用法建议

1. 画风基准图是 `assets/portraits/baimanman.jpg`（白小满）。**每张都把它当参考图一起传上去**，风格最稳；没有参考图功能时，至少保证同一个出图工具、同一个风格词。
2. 风格关键词：半写实游戏 CG 立绘（3A 人物图质感），清晰锐利、笔触干净、有画意。**不要厚涂、不要油画笔触、不要柔焦糊脸、不要磨皮成塑料，也不要纪实摄影那种「平光拍真人」的素人感。**
3. 每次改完提示词，跑 `tools\run.ps1 tools\gen-asset-manifest.js` 再跑 `tools\run.ps1 tools\build-single-file.js`，图片才会进 dist 单文件版。

```text
画风：半写实游戏 CG 立绘（3A 游戏人物宣传图那种质感，精修数字插画）：清晰锐利、笔触干净、有画意；semi-realistic game CG character art, clean rendering, sharp focus。绝对不要厚涂油画感、不要柔焦/景深糊脸、不要磨皮磨成塑料；也不要纪实摄影 / 新闻照 / 手机随手拍那种「平光拍真人」的质感。

这画的是游戏角色，不是证件照：五官要精致好看、轮廓干净、有辨识度（看一眼能记住），眼神要有光和情绪；但不要网红整容脸、不要浓妆、不要磨成假人。（男性角色：端正有型、带职业与生活痕迹，不要偶像剧奶油脸。）

光线：要有立绘感的打光 —— 主光把脸打亮塑形，加一点暖色补光和轻微的轮廓光 / 发丝光；脸要清楚，五官不能糊在阴影里，也不要惨白平光；缩到 68×88 的方块里也要能认出是谁。
质感：皮肤细腻干净（留一点点纹理即可，不要斑点、痘印、泛红、油光）；睫毛和发丝根根分明、头发有光泽；服装保留磨损、起球、灰尘等末日痕迹，但人不能脏得看不清。
禁止：不要第二个人、不要文字与涂鸦、不要海报标语；不要性感暴露、不要网红妆、不要卡通或日系画风、不要厚涂油画感、不要素人纪实感。
色彩：偏低饱和但明度适中：水泥灰、橄榄绿、锈铁橙、暖黄；避免高饱和霓虹，也避免整幅发闷发黑
画面里不要出现任何文字、logo 或界面元素（这张对应「shenxue」）。
```
